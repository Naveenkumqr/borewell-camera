# SR Enterprises — Borewell Camera Manufacturer Website

A responsive static website built with HTML, CSS and JavaScript. It includes service information, a process section, gallery, Instagram Reels cards, review cards, service areas, and phone/WhatsApp calls to action.

## Files
- `index.html` — page content and structure
- `style.css` — responsive design
- `script.js` — mobile navigation and footer year

## Before publishing
1. Search `98765 43210` and `919876543210` in `index.html` and replace the example phone/WhatsApp number with your own.
   - `tel:` links should use `+` and country code, e.g. `tel:+91XXXXXXXXXX`.
   - WhatsApp URLs should use country code and digits only, e.g. `https://wa.me/91XXXXXXXXXX`.
2. Confirm the business details, service/product locations, and Instagram profile links before publishing.
3. Replace sample gallery photos with your own genuine service photos.
4. Replace example review cards with real customer reviews and permission to publish them. Do not present placeholder reviews as genuine.
5. Review all service descriptions and remove anything your business does not provide.

## Preview locally
Open `index.html` in a browser. Internet access is required to load the remote stock photos and Google Fonts.

## Publish free with GitHub Pages
1. Create/sign in to a GitHub account at https://github.com/.
2. Create a **Public** repository named `borewell-camera-website`.
3. Upload `index.html`, `style.css`, and `script.js` to the repository root.
4. Open **Settings → Pages**.
5. Under **Build and deployment**, select **Deploy from a branch**.
6. Choose branch `main` and folder `/ (root)`, then click **Save**.
7. Wait for deployment. Your site URL will look like `https://YOUR-USERNAME.github.io/borewell-camera-website/`.

GitHub Pages documentation: https://docs.github.com/en/pages/getting-started-with-github-pages/creating-a-github-pages-site

## Google Search
After publishing, add the site in Google Search Console and use URL Inspection to request indexing. Indexing and ranking are not guaranteed. A custom domain is optional. For local discovery, consider a Google Business Profile if your business is eligible.

## Important notes
- This is a static site; it does not have a backend or a working enquiry form. The Google Maps link points to the location link supplied by the business owner. The phone and WhatsApp links are ready to use after you replace the placeholder number.
- Images are loaded from Unsplash URLs for demonstration. Keep internet access available, or replace them with your own optimized image files.
- The displayed customer reviews are placeholders and must be replaced before launch.
